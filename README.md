# 领克自动签到 LSPosed 模块

每天首次打开领克时，Hook 自动进入签到网页。网页出现“立即签到”按钮后，等待状态稳定 15 秒，再次确认仍为“立即签到”时点击。点击后继续确认页面变为“已签到”；若未生效，至少间隔 15 秒重试，同一网页每天最多尝试 3 次。模块内的定时功能可以负责打开领克；也可以使用手机自带的定时任务打开领克。

检测窗口约 3 分钟，重新回到领克页面时会重新检查缓存的 WebView。请让签到页保持在前台，等待按钮状态稳定及签到结果确认。LSPosed 日志会记录找到按钮、等待、点击、成功确认或超时；“已发送点击”不代表已确认签到成功。

## 使用

1. 安装 `app/build/outputs/apk/debug/app-debug.apk`。
2. 在 LSPosed 中启用“领克自动签到”，作用域选择“领克汽车” (`com.lynkco.customer`)，然后强制停止并重新打开领克。
3. 打开模块，点“立即测试打开签到页”，确认深链能打开领克。
4. 如需模块定时打开领克，选择每天的时间，打开“每天自动签到”，点“保存时间”。建议授予“定时权限”；未授权时系统可能明显推迟闹钟。若使用手机自带定时任务打开领克，可关闭模块内的定时开关。
5. 可用“1 分钟后测试定时启动”验证手机是否允许后台自动打开领克；测试不修改每天的时间。

手机需保持联网，领克登录状态需有效。模块内的定时启动由 Android 系统闹钟执行，不需要授予模块 Root 权限。模块应用若被系统标为“强行停止”，系统会取消它的闹钟；此时可用手机自带定时任务打开领克，Hook 仍会在领克启动时运行。已通过网页调试确认“立即签到”按钮为 `.sign-btn-box .sign-btn`，点击后页面变为“已签到”，连续签到天数增加。

在测试的真我手机上，模块退到后台后系统曾把原定次日 00:01 的内部闹钟推迟约三天。若需要准点打开，请使用手机自带的定时任务启动领克 App，Hook 会在当天首次启动时自动进入签到页。系统只提供“30 天内允许”跨应用启动授权；到期后可能需要重新允许。更新模块 APK 后请打开一次模块设置页，以便重新登记每日闹钟。

## 构建

使用 Android Studio 打开本目录，或运行 `gradle :app:assembleDebug`。本项目使用本地的 Xposed API 编译桩；这些类仅用于编译，不会打入模块 APK。

回归检查：配置 Java 17 或更高版本的 `JAVA_HOME`，运行 `node tests/sign-regression.mjs`。该检查直接提取生产代码中的网页脚本和轮询方法，覆盖加载缓慢、初始状态变化、缓存页面恢复、点击结果确认及重试限制；不能替代未签到账号的真机测试。
